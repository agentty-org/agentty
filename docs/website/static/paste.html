▌agenttypaste

Paste a screenshot into agentty, even over ssh

Terminals only carry text. This page turns an image or file into one line of text, and agentty turns that line back into the image. It all happens in your browser.

press Ctrl+V to paste
a screenshot, an image or a file, or drop one here

    show the text

    How

    1. Take a screenshot with PrtSc, or copy a file.
    2. Paste it here. The line of text is copied for you.
    3. Press Ctrl+Shift+V in agentty. It shows up as the image.

    Private by design

    • Nothing leaves this page. Your browser blocks every network request here: the page's Content-Security-Policy is connect-src 'none' and lets only the one script in this file run. Open your browser's network tab and paste to see it for yourself.
    • No accounts, cookies, storage or trackers. No libraries either. It's one small file you can read with View Source.
    • Screenshots lose their hidden data. A pasted screenshot or copied image is redrawn before it's encoded, so things like a photo's GPS location don't come along. A file (dropped, chosen, or copied in your file manager) is sent byte for byte, as it is.
    • Checked on arrival. The line carries a SHA-256 of the data. agentty checks it and refuses anything that changed on the way.
    • Only ever data. agentty turns the line back into an image or file. It never runs it.
    • The same page, offline. agentty paste page > paste.html writes this exact page, and agentty's tests check the website's copy matches it byte for byte.
    Only needed when your laptop can't hand agentty its clipboard, like Terminal.app over ssh. Run agentty paste setup on your laptop once and Ctrl+V in agentty pastes images by itself, with no size limit. More in Clipboard & Images.
